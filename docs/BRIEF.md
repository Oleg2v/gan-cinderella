### 4. ВЛАДЕЛИЦА (дашборд и автоматизации)
- KPI: дети сегодня, заполненность групп, лист ожидания, экскурсии на неделе, заявки по источникам (сайт, Facebook, русский портал), оплачено и ждет оплаты, кто на смене
- Воронка с анимацией: посещение сайта → экскурсия → регистрация → оплата
- «מאחורי הקלעים»: карточки автоматизаций с тумблером, временем последнего запуска и мини-схемой «триггер → действие». По нажатию проигрывается анимация:
  - новая заявка с сайта → сразу сообщение родителю со слотами экскурсии и уведомление владелице
  - экскурсия завтра → напоминание; после экскурсии → ссылка на регистрацию
  - освободилось место → предложение следующей семье из листа ожидания
  - 1-е число → счет, 5-е → мягкое напоминание, квитанция уходит сама
  - 17:30 → вечерние сводки
  - среда → напоминание о הורי שבת
  - не хватает документа → напоминание родителю
  - завтра день рождения → напоминание команде
  - меню недели сверяется с аллергиями детей → предупреждение кухне
