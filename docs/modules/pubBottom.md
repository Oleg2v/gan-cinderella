# Module brief: pubBottom (view: visitors)

MODULE pubBottom: the rest of the public site (after pubTop's clock) + all its flows + the footer. Sections in this order, each a .band with .wrap, alternating grounds (paper / sky / blush / white) with occasional scalloped edges; strong section heads (eyebrow + h2 + lead).

1) #kids-world "מה מחכה לילדים":
 - Kitchen: a plate that ASSEMBLES itself when revealed (plate slides in, food shapes drop in one by one with springy bounces, steam curls). Copy: own kitchen, fresh food every day: breakfast, lunch, מנחה; menu approved by a dietitian. Three meal chips.
 - Three clubs (music / sport / nature & animals = טבע-חיות) as three cards, each with its own small looped animation that plays on hover/tap/in-view: notes floating from a tiny xylophone; a ball bouncing; a leaf swaying + a bunny hopping. "3 חוגים בכל שבוע".
 - "פתוחים בחול המועד" card: a mini calendar strip where the חול המועד days light up; copy: fewer vacation days than the official calendar, open in חול המועד סוכות and פסח.
2) #recognized "מעון מוכר ומפוקח": seal/shield illustration + text; the subsidy discount line (no numbers). Button "בדיקת זכאות" -> openEligibility(): sheet with 3 mock steps (chips/toggles, no numbers: e.g. employment/studies status, family size bucket, already have a file?) with a progress indicator -> final screen "נשלח לכם מדריך בוואטסאפ" + a phone mock (App.ui.phone(...).chat(...)) showing a neutral message with a short generic guide (no invented government facts or numbers) + sparkle burst.
3) #availability "מקומות פנויים" (example data, visibly tagged): three group cards (תינוקייה, צעירים, בוגרים) each with a seat visualization (little cribs/chairs) and a status (e.g. "2 מקומות פנויים", "מקום אחרון", "רשימת המתנה"). CTAs: reserve -> openRegistration({group}) or join the waitlist. Waitlist sheet: child name + birth date + group -> result "אתם במקום 3 בתור" with an animated queue of little figures where theirs is highlighted, and "נעדכן בוואטסאפ כשמתפנה מקום". Also "check my place" with a mock reference number.
4) #visit "סיור בגן": inline teaser (castle-door illustration + 3 short bullets of what you will see) + button -> openBooking(). Booking sheet: choose a day (next ~10 opening days as chips / mini calendar, Sun-Thu, some marked full), choose a slot (example slots), parent name + phone (mock validation, dir=ltr), language for messages (עברית / Русский), confirm -> success: animated stamp/seal, summary card and a phone mock with a neutral message preview in the chosen language (incl. the address העצמאות 58, אשדוד) + "נשלח גם תזכורת יום לפני" + burst. The primary button of each step reachable without awkward scrolling at 390x844.
5) #register "הרשמה": 3-step sheet (size 'full' on phone). Progress = a GLASS SLIPPER (SVG) that fills with sparkly liquid as steps complete (1/3, 2/3, full + shine). Step 1 child: name, birth date -> group chosen automatically with a satisfying animation (rule, labelled as example: < 12 months תינוקייה, 12-24 צעירים, 24-36 בוגרים, older -> friendly note). Step 2 parents: name, phone, preferred language for messages. Step 3 documents: 3 rows (e.g. ספח תעודת זהות עם פרטי הילד, פנקס חיסונים, אישור זכאות לסבסוד אם יש) each via <input type=file> OR "use a sample file" -> animated check. Finish -> slipper glows, sparkles, "ההרשמה נשלחה" + what happens next.
6) #reviews: 3 placeholder cards (quote glyph, skeleton lines, avatar placeholder circles) + the caption "כאן יופיעו המלצות של הורים". Tasteful, intentional, not broken-looking.
7) Assistant "שאלו אותנו": floating button at the bottom inline-end above the dock (bottom: calc(var(--dock-h) + 22px + var(--safe-b))), shown only after the hero is scrolled past (scrollY > innerHeight*0.8), hidden during the tour (html.is-touring) — it lives inside your view so other views hide it automatically. Plus a CTA inside the page. Chat sheet: greeting, quick-reply chips (שעות פתיחה, אוכל, חוגים, הנחה לזכאים, הסתגלות, כתובת, סיור בגן), answers in the current language (he/ru) using ONLY facts, typing indicator before each answer, free-text input matching keywords in he/ru (שעות/часы/еда/скидка...) with a friendly fallback offering WhatsApp + booking. Adaptation answer: warm, no invented policy, invite to talk at the visit.
8) #contact FOOTER: a deep-night band (navy, stars, castle silhouette with lit windows, moon): logo (data-logo), name + slogan, address + "Google Maps" link (https://www.google.com/maps/search/?api=1&query=%D7%94%D7%A2%D7%A6%D7%9E%D7%90%D7%95%D7%AA%2058%20%D7%90%D7%A9%D7%93%D7%95%D7%93), hours (Sun-Thu 07:00-17:00 with extension to 18:00, Fri 07:00-13:00), two WhatsApp buttons (generic chat icon + "WhatsApp" + number in <bdi dir="ltr">), Facebook link, a "הצהרת נגישות" button -> App.ui.statement(), and the credit "עוצב ופותח ע״י Kikkey" linking https://kikkey.com. No phone-call buttons anywhere.

Public methods (required, exact names): openBooking(opts), openEligibility(), openRegistration(opts), openAssistant().
Tour fn: tour.booking(ctx): scroll to #visit, ctx.tap its button, tap a day chip, tap a slot, ctx.type the name (e.g. "מיכל" in he / "Михаль" in ru) and a phone, tap confirm, wait on the success + message preview (~2.5s), close the sheet. <= 10s.
